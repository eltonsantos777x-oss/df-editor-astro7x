Otimização de Performance

Ajuste os parâmetros do Windows para remover atrasos de entrada, desativar serviços inúteis e extrair o máximo de FPS do seu hardware.

Processador e Memória

Desativar HPET (High Precision Event Timer)
Reduz micro-stuttering (engasgos) e diminui a latência do sistema forçando o uso de timers mais rápidos (TSC).
CPU Core Unparking
Impede que o Windows coloque núcleos do processador em modo de economia, garantindo resposta imediata.
Otimização de Agendamento RAM (LargeSystemCache)
Ajusta o comportamento do cache de memória para priorizar programas em primeiro plano (jogos).

Periféricos e Input Lag

Polling Rate Force (1000Hz+)
Remove limitações do Windows para portas USB, permitindo taxas de atualização máximas para mouse e teclado.
Desativar Mouse Acceleration (FSE)
Desativa completamente a curva de aceleração nativa via registro para rastreamento 1:1 raw (perfeito para FPS).
Desativar Suspensão Seletiva USB
Previne que o Windows desligue portas USB para economizar energia, evitando falhas de registro de cliques.

Serviços do Windows

Desabilitar Telemetria (Data Collection)
Bloqueia o envio de dados diagnósticos para a Microsoft em segundo plano, liberando CPU e rede.
Game Mode Force (Prioridade Realtime)
Ajusta o Win32PrioritySeparation no Regedit para focar todos os ciclos de CPU no processo em foco na tela.

Rede e Latência

Otimizar TCP/IP (Nagle's Algorithm)
Desativa o atraso no envio de pacotes de rede (TcpAckFrequency), reduzindo o PING e hitreg delay em jogos multiplayer.
DNS Cache Optimization
Aumenta o limite de cache e reduz consultas redundantes (MaxCacheTtl), estabilizando rotas.
Aviso: Modificar configurações avançadas do sistema pode exigir um reinício para aplicar os efeitos completos.
