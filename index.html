Integração Automática Cloudflare

Tudo mastigado para você!

Como não tenho acesso direto à sua conta Cloudflare por questões de segurança, criei este guia automático. Você só precisa copiar e colar os itens abaixo no painel do seu domínio.

1 Configurar DNS

Acesse o Cloudflare, vá em DNS > Registros e adicione os 4 registros abaixo:

MX @ route1.mx.cloudflare.net Pri: 1
MX @ route2.mx.cloudflare.net Pri: 2
MX @ route3.mx.cloudflare.net Pri: 3
TXT @ v=spf1 include:_spf.mx.cloudflare.net ~all

2 Ativar Roteamento de Email

Ainda no Cloudflare, vá no menu lateral em Email > Roteamento e clique no botão azul Get Started (Começar).

3 Criar Worker (Captura de Emails)

Vá em Workers & Pages > Criar Application > Create Worker. Chame de astro-mail e cole o código abaixo:

export default {
  async email(message, env, ctx) {
    // Worker para capturar emails do domínio astro7x.online
    // Em breve, conectaremos nossa API de banco de dados aqui.
    console.log(`Email recebido para a conta: ${message.to}`);
  }
}

Por fim, volte em Email > Roteamento > Rotas, adicione uma regra "Catch-all" (Pegar tudo) e selecione a opção "Enviar para Worker", escolhendo o astro-mail.
